# Qinux

> A modern, customizable Linux distribution built on Arch Linux.

Qinux is a modern Linux distribution focused on **simplicity, customization, performance, and freedom**.

Built on top of Arch Linux and powered by KDE Plasma, Qinux aims to provide a clean and polished desktop experience without taking away the flexibility that Linux users expect.

## ✦ What is Qinux?

Qinux is designed to be a Linux distribution that stays out of your way.

Instead of creating everything from scratch, Qinux builds on proven open-source technologies and adds the tools, defaults, configuration, and experience needed to make them work together as a complete operating system.

**Arch underneath. Qinux on top.**

## 🚀 Features

* 🐧 **Arch Linux base** — Rolling-release and up to date
* 🖥️ **KDE Plasma** — Modern and highly customizable desktop
* ⚙️ **Calamares installer** — Simple graphical installation
* 🎨 **Customizable** — Make Qinux your own
* 📦 **Native package management** — Built around the Arch ecosystem
* 🔓 **Open source** — Built with open-source software
* ⚡ **Performance focused** — Minimal unnecessary components
* 🧩 **Modular architecture** — Qinux components are developed independently
* 🛠️ **Developer friendly** — Built with modern development tools and technologies

## 🧱 Architecture

Qinux is organized into independent components rather than one giant codebase.

```text
Qinux
├── Installer
├── Desktop
├── System
├── Packages
├── Themes
├── Applications
├── Configuration
└── Infrastructure
```

This makes individual parts easier to develop, maintain, replace, and improve.

## 🖥️ Desktop

Qinux uses **KDE Plasma** as its primary desktop environment.

The goal is not to heavily modify Plasma, but to provide a carefully configured experience while keeping Plasma's customization capabilities intact.

Users can change the desktop to fit their own workflow instead of being locked into a predefined interface.

## 📦 Software

Qinux uses the Arch Linux ecosystem as its foundation.

Software can be installed and managed using the familiar Arch package ecosystem while Qinux-specific packages and components can be maintained separately.

Qinux does not aim to replace the entire Linux ecosystem.
It aims to make that ecosystem easier to use.

## 🧩 Modularity

Qinux is built around reusable components.

For example:

* Installer modules
* Desktop configuration
* System utilities
* Themes
* Wallpapers
* Qinux-specific applications
* Package definitions
* Documentation

Each component can evolve independently without requiring the entire distribution to be redesigned.

The exact technology used by individual components may change as the project evolves.

## 🎯 Goals

Qinux aims to:

1. Provide a clean Arch-based desktop experience.
2. Make Linux easier to install and configure.
3. Preserve user control and customization.
4. Avoid unnecessary complexity.
5. Keep the system modular and maintainable.
6. Build useful native tools where they provide real value.
7. Remain open source and community-driven.

## 🌱 Project Status

Qinux is an evolving project.

Things will change. Components may be replaced, redesigned, or removed as the project develops.

The goal is not to rush toward a release, but to build a distribution that can remain useful and maintainable over time.
